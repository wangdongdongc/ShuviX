# ShuviX Extension

A browser-native AI assistant (Chrome MV3) that lives in the side panel. The agent runs inside the browser and works alongside whatever you're browsing, keeping its help in the flow of your work on the web.

Built on the shared `@shuvix/chat-ui` and `@shuvix/agent-runtime` packages.

## Develop

```bash
npm run dev -w @shuvix/extension     # Vite dev
npm run build -w @shuvix/extension   # Build the unpacked extension
```
