# 标记、标注与骨架

那种安静、考究的观感，靠的是几条固定规格加两处留白。整张图里只有数据有资格显眼。

## 标记规格

| 标记 | 规格 |
|---|---|
| 柱 / 条 | 按 `viewBox` 单位最多约 24 粗；绝不填满槽位——剩下的那条带就是空气。数据端 `rx="4"`，基线端保持方角 |
| 折线 | `stroke-width="2"`、`stroke-linejoin="round"`、`stroke-linecap="round"` |
| 点标记 | `r` 不小于 4（直径 8），用系列色填充 |
| 面积填充 | 系列色相约 10% 不透明度——一层薄雾，绝不是一块饱和色。用 `fill-opacity="0.1"`，不要换一个更浅的 token |
| 网格线 | `stroke="var(--viz-grid)"`、`stroke-width="1"`、**实线** |
| 坐标轴 / 基线 | `stroke="var(--viz-axis)"`、`stroke-width="1"`、实线 |

网格线是最后手段：先用直接标注，只有当读者仍然需要跨越一段距离比较时才加。绝不画成虚线——虚线的意思是「预测」或「阈值」，而这只是一条网格。

## 两处留白——分隔由底色来做

- **底色缝。** 相邻的标记之间留 2 个单位的卡片底色：堆叠柱的每一段、相邻的每一对柱子。同一张图里宽度处处一致。做法是把标记改小，而不是画点什么上去。
- **底色环。** 压在折线上或彼此重叠的点，加 2 个单位的底色描边：`stroke="var(--theme-bg-secondary)" stroke-width="2"`。

**绝不用描边把标记框起来做分隔。** 描边添的是不属于数据的墨。缝和环才是机制。

## 标注

- **直接标注，而且有选择地标。** 图的每一部分都必须不靠颜色就能辨认——但给**每一个**点都配一个数字是混乱，而且没人看。每条系列点名一次，再挑出端点、极值、或者论证真正落脚的那一个值。
- **文字绝不穿系列色。** 标注、数值、轴文字用 `--theme-text-secondary` 或 `-tertiary`；身份由文字**旁边**那个着色标记承载。好几个槽位在某些主题底色上作为文字是读不清的——所以这是正确性规矩，不是风格偏好。唯一的例外是写在分类浅底上的文字，它用那个槽位的 `--viz-N-ink`。
- **标注放在标记外面。** 手写 SVG 量不了文字，所以塞进柱子里的标注是一次迟早会输的押注，而被裁掉的标注比没有更糟。横柱 → 数值放在端点之后。纵柱 → 数值放在柱顶之上。折线 → 名字放在右端。
- **锚点要想清楚。** 左侧栏的行标签用 `text-anchor="end"`，纵柱下方用 `middle`，横柱端点之后用 `start`。手摆的网格看起来齐不齐，就取决于这个。
- **竖直居中。** SVG 的文字坐在基线上，所以要在 `y` 处居中的标注，11 单位字号大约落在 `y + 4`。`dominant-baseline` 各渲染器行为不一致——自己算这一下就好。
- **字号。** 需要被读的，11 单位是底线，轴刻度也不例外。`font-family="var(--theme-font-sans)"` 写在外层 `<g>` 上，别每个 `<text>` 都写一遍。
- **需要竖向对齐的数字列**加 `style="font-variant-numeric: tabular-nums"`。单独一个大数字**不要**加——等宽数字会让它显得松垮。

## 图例

图例是给两条以上系列、**且直接标注够不到它们全部**时用的。单系列不需要：标题已经说了画的是什么。真要画时，它是一排 `<rect>` 色块（约 8×8，`rx="2"`）配 `--theme-text-secondary` 的文字，摆在图的**上方**而不是旁边——侧边图例抢的是图本身需要的宽度。

直接标注优先于图例；图例优先于网格线；网格线优先于别的一切。

## 骨架

给图留出空气：左侧栏要宽到放得下最长的行标签，另外三边留约 12–16 单位的边距。挤到 `viewBox` 边缘，是手画的图显得没完工的最常见原因——而且由于卡片是裁切溢出而不是滚动，这也是图的一部分凭空消失的最常见原因。
