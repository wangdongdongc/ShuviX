# 反模式——画成这样就是错的

每张图发出去之前拿这份清单过一遍。对上哪一条，它就是错的，改掉。这一步的价值高于本技能里的任何其他内容。

## 编码

**一张图上两根 y 轴。** 两套刻度怎么对齐是任意的，于是图凭空造出一个数据里没有的相关性。这是图表里最严重的一个错误。
→ 拆成两张图，或者把两条系列都归一到共同基准（起点 =100）画在**一根**轴上。

**给本身无序的类别套值阶。** 类别是产品或团队时还按「越大越深」上色，等于把柱长重复编码成色相，把唯一空闲的通道花在图已经显示过的信息上，而且必然过不了色板的校验。
→ 每根柱子同一个颜色（`--viz-1`）。色阶只给有序的东西。

**造出来或复用的第 9 个色相。** 在色觉缺陷下与某个既有槽位无法区分，而且跟不了主题。
→ 尾部归入「其他」，或者拆图。

**跳着取槽位**（因为喜欢就拿 `--viz-5` 当第一条）。那个顺序**就是**色觉安全机制。
→ 按 1、2、3……依次取。

**拿状态色当普通系列**，或者拿系列色去表示好坏。
→ 只有颜色**真的表示**一个状态时才用状态 token。

**双向色的中点放了一个色相，或者两极都是冷色。** 中点必须读作「什么都没有」，两极必须读作对立。
→ `--viz-1` ↔ `--viz-mid` ↔ `--viz-8`。

**柱子的基线被截断。** 柱形编码的是长度，起点不为零会放大每一处差异。
→ 从零开始，或者换一种形态。

## 形态

**故事只是一个数字，却上了八个颜色。** 这是一张图错过自己重点的最常见方式。
→ 强调：一个槽位，其余置灰。或者干脆把那个数字写进句子。

**一根柱子的柱状图，或者两瓣的饼图。**
→ 那个数字本身就是图。写进句子里。

**用饼图/环形图比较接近的值。** 角度是判断不了的。
→ 排好序的柱子。部分与整体只求一眼的印象，且最多约 6 段。

**一张把上面那句话重说一遍的图。** 散文已经说了，这张图就是装饰。
→ 删掉，或者让它去显示散文给不出的东西。

**次序毫无含义却不排序的柱子。**
→ 按值排序；那才是读者要来做的比较。

## 标记与骨架

**粗重饱和的色块、显眼的网格线、不留余地。** 读起来吵，而且显得没完工。
→ 细笔、发丝级的退让骨架、宽裕的留白。饱和填充属于小标记。

**虚线的网格或坐标轴。** 虚线的意思是「预测」或「阈值」；画在普通网格上就只是噪音。
→ 实线发丝，比底色深一档。

**用描边把标记框起来做分隔。**
→ 2 单位的底色缝；重叠的点用 2 单位的底色环。

**给每一个数据点都标了数字。**
→ 只标端点、极值、真正要紧的那一个。其余放手。

**被自己的标记裁掉的标注**，或者跑出 `viewBox` 的文字。卡片是裁切溢出的，所以越界的部分直接消失。
→ 标注放在标记外面；四边留边距；重读一遍渲染结果。

**用系列色写的文字。** 好几个槽位在某些主题底色上低于 3:1，作为文字就读不清了。
→ 一律文字 token；身份由文字旁边那个标记承载。

**写死的十六进制、`white`、`black`，或者一块固定的背景矩形。** 它只能在 11 套主题里的一套下成立。
→ 只用 token。底色卡片已经给了。

**根节点上写了 `width`/`height`，或者没有 `viewBox`。** 卡片按 `viewBox` 缩放，其余裁掉。
→ 只写 `viewBox`。

## 结构

**示意图里交叉的箭头**，而重排框就能避开。
→ 重排。交叉几乎总是排版失败，而不是关于这个系统的事实。

**超过约 10 个框。** 再多没人读。
→ 砍掉一层细节，或者拆成两张图。

**流向混着来**——有的朝下、有的朝右、有的又拐回上面。
→ 一个流向，回边在视觉上另作区分。

## 观感

完整的指南在 `references/style.md`；下面这些，是让一张画对了的图看起来还没画完的失误。

**字太重** —— `font-weight` 写 600、700 或 `bold`，或者标注里某个词加粗。
→ 只用 400 和 500；框标题、头条数字用 500。

**英文标注每个词首字母大写，或者全大写**（标注、轴名、按钮）。
→ 只有句首大写；中文不加粗。

**emoji、图标字符、装饰性编号。**
→ 靠形状、位置和几个字。

**图里放标题或整段文字。**
→ 标题是 `aria-label` 和图前面那句话；解释写在回复里。

**渐变、阴影、发光、背景矩形。**
→ 纯色平涂；卡片本身就是底。

**每个框一种颜色** —— 按位置排出一道彩虹。
→ 缺省中性；只有种类才上色，最多三种，按槽位顺序。

**浅底上写灰字或系列色的字**，或者用 `opacity` 把字调淡。
→ 用那块浅底的 ink：`--viz-N-tint` 上写 `--viz-N-ink`。

**2 或更粗的边框**，或者每个框都描一圈饱和色。
→ 一律 1，唯一的强调 1.5。

**原始数字** —— `0.30000000000000004`、`2653.2977`、每个刻度上都带单位。
→ 取整、带格式，单位只写一次。

**挤** —— 标注贴着框边，图从 `viewBox` 的这一边顶到那一边。
→ 四边留边距；几何按 `references/diagrams.md` 算。
