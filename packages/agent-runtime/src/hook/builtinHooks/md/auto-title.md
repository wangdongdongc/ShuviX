---
shuvix: hook v1
shuvix-builtin: true
name: auto-title
shuvix-displayName: Automatic Session Titles
description: Names a session on its first prompt and refines the title once after the second turn.
shuvix-hook-agent: titler
shuvix-hook-on:
  - trigger: session.prompt-accepted
    when: event.isDefaultTitle
  - trigger: session.turn-completed
    when: event.titleAutoGenerated && event.turnCount == 2 && event.textMessageCount >= 3
---

Derive one concise title for this session from the event below and apply it with the `session` tool. On `session.prompt-accepted` the excerpt is `promptText`; on `session.turn-completed` it is `recentText`. Then finish.
