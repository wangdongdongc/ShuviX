---
shuvix: policy v1
shuvix-builtin: true
name: protect-shuvix-config
shuvix-displayName: ShuviX 自身の設定を変える前に必ず確認
description: ShuviX のポリシー・エージェント・hook・スキルへの書き込みは必ずあなたに確認します —— 自動審査も確認なしスイッチも代わりに答えません。
shuvix-policy-scope:
  subject.kind: [agent]
  object.type: [path]
  env.host: [desktop]
shuvix-policy-rules:
  - effect: force-ask
    action: [write]
    match: inDir(object.path, vars.shuvixConfigDirs)
    prompt: >-
      この書き込みは ShuviX 自身の設定を変えます —— セキュリティポリシー、エージェントの指示、
      自動で動く hook、またはスキル。これからエージェントに何ができるかを決めるもので、自動審査
      そのものも含まれます。diff を確認してください。
---

**何をするか**：エージェントがファイルツールで `~/.shuvix/policies`、`~/.shuvix/agents`、
`~/.shuvix/hooks`、`~/.shuvix/skills` の下に書き込むときは、必ず先にあなたに確認し、**確認なし
スイッチがオンでも確認します**。自動審査も代わりには答えません：`force-ask` は常にあなた本人に
届きます。

**なぜか**：これらのファイルは中身ではなくルールです。ポリシーはエージェントに何ができるかを
決め、エージェントファイルはシステムプロンプトであり、hook は自分でエージェントを起動し、スキルは
指示として読まれます。自動審査そのものもこれらでできています —— レビュアーはエージェントファイル、
それを起動するのは hook ファイルで、同名のファイルは組み込みのものを上書きします。これらがあなたに
見えないところで変えられるなら、注入された一つの指示で、以後のすべてのチェックを永久に止められて
しまいます。

**しないこと**：

- 対象はファイルツールだけです。コマンドはサンドボックスが有効ならそれが止めます（サンドボックスも
  コマンドに `~/.shuvix` への書き込みを許しません）。サンドボックスの外で動くコマンドは他と同じく
  審査され、レビュアーは ShuviX の保護を変えることを有害として扱います。
- ノートブックでのあなた自身の編集はエージェントの書き込みではなく、確認されることはありません。
  ノートブックのエージェントにこれらのファイルを変えさせると、変更のたびに確認します —— それが狙いです。
- bot ファイルには専用のポリシー protect-bot-files があります。

**調整するには**：上書きコピーを作って編集してください —— 慎重に。
