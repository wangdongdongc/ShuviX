---
shuvix: policy v1
shuvix-id: policy:builtin:network-admission
shuvix-builtin: true
name: network-admission
shuvix-displayName: リモートアクセスはこのコンピューターからのみ
description: リモートアクセスがオンの間、接続できるのはこのコンピューター上のブラウザーだけです。自分の network-admission でこのポリシーを置き換えるまで、ほかのデバイスはすべて拒否されます。
shuvix-policy-scope:
  subject.kind: [network]
  object.type: [request]
shuvix-policy-rules:
  - effect: deny
    action: [request]
    match: "!inCidr(subject.address, ['127.0.0.0/8', '::1'])"
    prompt: この ShuviX は、動作しているコンピューターからの接続しか受け付けません。このデバイスから接続するには、そのコンピューターで（または SSH トンネル経由で）ShuviX を開き、設定 → 一般 → ネットワークアクセス で接続できる相手を設定してください。
---

**何をするか**：リモートアクセスでは、ブラウザーがネットワーク越しに ShuviX を使えます ——
このコンピューターで ShuviX ができることはすべて、しかもパスワードなしで。このポリシーは
それをこのコンピューター上のブラウザーに限ります：送信元がこのコンピューター（`127.0.0.1`
または `::1`）でない HTTP リクエストはすべて拒否され、相手のデバイスには ShuviX の代わりに
上の一文が表示されます。SSH トンネル経由の接続は `127.0.0.1` から来るので通ります。

**ほかのデバイスを入れるには**：このポリシーを置き換えます —— 自分の
`~/.shuvix/policies/network-admission.md`（同じ `name`）を書いてください。`allow` ルールを
持つ別のポリシーを足すだけでは足りません：`deny` はすべての allow に勝ちます。
設定 → 一般 → ネットワークアクセス のボタンを押すと、そのためのプロンプトを入れた新しい会話が
開きます：エージェントがどのデバイスを接続させ、それぞれに何を許すかを尋ね、ShuviX
ナレッジベースの `network-policy` エントリーを読んでファイルを書きます。

**しないこと**：

- パスワードではありません。置き換えた後は、誰が入れるかはあなたのポリシーが決めます ——
  アドレス、ネットワーク、デバイス、そのほかリクエストが運ぶものなら何でも。
- ポリシーの内容にかかわらず、三つのチェックは常に残ります：送信元がプライベートネットワーク上
  （またはこのコンピューター）であること、`Host` ヘッダーが IP アドレスか `localhost` と ShuviX の
  ポートであること、WebSocket が ShuviX 自身の配信したページから来ること。
- このポリシーを（置き換えずに）無効にすると、ローカルネットワーク上のすべてのデバイスが入れます。
