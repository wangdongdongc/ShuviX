---
shuvix: policy v1
shuvix-builtin: true
name: review-knowledge-writes
shuvix-displayName: ナレッジベースへの書き込みは必ず確認
description: ナレッジベースへのエントリの書き込みは、自動許可がオンでも必ず先に確認します —— セッション要約は除きます。
shuvix-policy-scope:
  subject.kind: [agent]
  object.type: [path]
  env.host: [desktop]
shuvix-policy-rules:
  - effect: force-ask
    action: [write]
    match: inDir(object.path, [vars.knowledgeRoot]) && !inDir(object.path, vars.knowledgeSessionDirs)
    prompt: ナレッジベースのエントリは一度書かれると、同じスコープの後続セッションすべてに読み戻されます。許可する前に、残す価値があるか確認してください。
---

**何をするか**：エージェントがナレッジベース（`~/.shuvix/knowledge`）のエントリを作成・変更
しようとすると、まずあなたに確認します —— `knowledge` ツール経由でも、ファイルを直接書く
場合でも、同じゲートに掛かります。他の確認ゲートと違い、セッションの自動許可スイッチが
オンでもこのゲートは確認します。

**何を通すか**：各 `sessions/` ディレクトリです。セッション要約はホストが自動的に更新し
続けるメモで、更新のたびに確認していては「自動」がプロンプトの連続になってしまいます。
それらはドラフトのまま、ナレッジベースのページであなたがレビューします。

**何をしないか**：

- 対象はファイルツールと `knowledge` ツールだけです。許可すれば、エージェントはコマンドで
  エントリを書くこともできます。
- エントリの良し悪しは判断しません —— それはあなたのレビューの役目です。書き込みを許可
  することは検証ではありません。アプリで印を付けたときにだけ、エントリは検証済みになります。
- 読み取りは制限しません。想起は自由なままです。

**調整するには**：同名の上書きコピーを作ります。効果を `ask` に変えると、ナレッジベースへの
書き込みは他の書き込みと同じ扱い（自動許可がオンなら省略）になります。`sessions` の節を
外せば要約も確認対象になり、ルールを削除すれば確認しなくなります。
