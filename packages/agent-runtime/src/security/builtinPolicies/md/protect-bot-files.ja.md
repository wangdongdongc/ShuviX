---
shuvix: policy v1
shuvix-builtin: true
name: protect-bot-files
shuvix-displayName: bot が自分を書き換える前に必ず確認
description: bot ファイルへの書き込みは常に確認します —— 自動許可でも素通りしません。
shuvix-policy-scope:
  subject.kind: [agent]
  object.type: [path]
  env.host: [desktop]
shuvix-policy-rules:
  - effect: force-ask
    action: [write]
    match: inDir(object.path, [vars.botsDir])
    prompt: >-
      この書き込みは bot 自身のファイルに対するものです —— 自分が誰で何を覚えて
      いるか。以後すべての会話でシステムプロンプトの一部として読み戻されます。diff を
      確認してください：新しい嗜好や事実を書き足すのはこのファイル本来の用途ですが、
      人格の書き換えは「その bot が誰か」を変える行為です。
---

**何をするか**：bots ディレクトリ配下へのあらゆる書き込みを、**自動許可がオンでも**
毎回確認します。

**なぜ拒否ではないか**：bot はただの markdown であり、「bot の下書きを手伝って」は
まったく正当な依頼です。拒否すればそれごと塞いでしまいます。確認なら道を残したまま、
自分のファイルの書き換えが画面外で起こらないことを保証できます。

**なぜ自動許可を貫くか**：bot ファイルは、エージェントが**自分自身について**編集する
唯一のファイルです。その本文はその bot セッションのシステムプロンプトに入り、bot は自分で
それを最新に保つことを求められています —— 述べられた嗜好、訂正、苦労して確かめた事実。
その編集はあなたに答えている最中に起こり、以後の会話すべてに効き続けます。人格をひそかに
書き換える編集や、覚えていたことを半分削る編集こそ、このカードが目の前に出す対象です。

**できないこと**：

- ファイルツールのみを対象とします。bot セッション自身のエージェントはコマンドを実行
  できませんが、派遣したサブセッションは実行できます —— そして bash の書き込みはパス
  ポリシーを通りません。そちらの担保は監査記録と、サブセッションが開いて読める可視の
  会話であることです。
- 読み取りは対象外です。bot 本文はすでにそのシステムプロンプトに入っています。
