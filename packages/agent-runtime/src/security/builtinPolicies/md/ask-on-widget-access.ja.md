---
shuvix: policy v1
shuvix-id: policy:builtin:ask-on-widget-access
shuvix-builtin: true
name: ask-on-widget-access
shuvix-displayName: ウィジェットを使う前に確認
description: エージェントはこのセッションの権限表にあるウィジェットを自由に使えます。それ以外のウィジェットを使うときは先に確認します。
shuvix-policy-scope:
  subject.kind: [agent]
  object.type: [widget]
  env.host: [desktop]
shuvix-policy-rules:
  - effect: ask
    action: [read]
    match: >-
      !(object.widgetId in vars.aclWidgetRead)
    prompt: エージェントがこのウィジェットに記録したあなたのデータを読めるようになります。
  - effect: ask
    action: [write]
    match: >-
      !(object.widgetId in vars.aclWidgetWrite)
    prompt: エージェントがこのウィジェットの記録、またはウィジェット自体を変更できるようになります。ウィジェットの画面で操作するのと同じ効果です。
---

**何をするか**：エージェントは `widget` ツールであなたのウィジェットを使います。各ウィジェットには
それぞれの操作（画面が使うのと同じもの）があり、どの操作も記録を読むか変更するかのどちらかです。
次のものは確認しません：

- **このセッションの権限表にあるウィジェット** —— 確認カードの「許可して記憶」でそこに行が書かれます。
  行は**読み取り**（読み取り操作の呼び出しとプレビュー）か**読み書き**（すべての操作の呼び出しと、
  ウィジェット自体の変更：ビルド、データへの SQL、エクスポート）のどちらかです。
- **このセッションが作ったウィジェット** —— 作成時に読み書きの行が付きます。

それ以外は**確認します**。一度だけ許可したウィジェットは次回も確認されます。記憶すれば確認されなくなります。
行はセッション設定の「ウィジェットアクセス」にあり、読み取りと読み書きの切り替えや削除ができます。

**なぜ確認するか**：ウィジェットにはあなた自身の記録 —— 読書リスト、家計、ログ —— があります。
エージェントにウィジェットを使わせると、それを読んだり変更したりできます。ウィジェットのコードを変えると、
その後のすべての呼び出しの動作が変わります。

**しないこと**：

- 自動レビューはこの確認に答えません：内蔵 hook `auto-review` はウィジェットアクセスをあなたに任せるので、
  すべてのカードがあなたに届きます。
- どんなウィジェットがあり、どんな操作があるかを調べるときは確認しません。
- 許可は一つのセッションのものです。サブセッションは作成時に親の許可を、フォークは元の許可をコピーします。

**調整するには**：上書きコピーを作って編集します。読み取りのルールを外すと、どのセッションも確認なしで
すべてのウィジェットを読めるようになります。
