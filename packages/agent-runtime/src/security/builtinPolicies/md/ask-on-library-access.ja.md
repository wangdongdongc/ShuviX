---
shuvix: policy v1
shuvix-id: policy:builtin:ask-on-library-access
shuvix-builtin: true
name: ask-on-library-access
shuvix-displayName: ライブラリの他のファイルを読む前に確認
description: エージェントはこのセッションに属するライブラリのファイルを自由に読めます。ファイルライブラリのそれ以外のファイルを読むときは先に確認します。
shuvix-policy-scope:
  subject.kind: [agent]
  object.type: [library]
  env.host: [desktop]
shuvix-policy-rules:
  - effect: ask
    action: [read]
    match: >-
      !(has(object.linked) && object.linked)
    prompt: この会話で使われていないファイルライブラリのファイルを、エージェントが読めるようになります。
---

**何をするか**：ノートと会話は `shuvix://file/…` リンクでファイルライブラリのファイルを指し、エージェントは
`read` でそれを開きます。このセッションに属するライブラリのファイルは自由に読めます：

- この会話であなたが送った画像
- このセッションのノートにあなたが貼り付け・ドロップ・挿入したファイル

ノートにライブラリのリンクが書かれているだけでは数えません。ノートはエージェントも書けるからです。

それ以外のライブラリのファイルを読むときは**確認します**。

**なぜ確認するか**：ライブラリにはすべてのノートと会話のファイルが入っています。そのリンクは、エージェントが読むノート、
Web ページ、ツールの結果など、どこにでも現れます。リンクをたどるだけで、別の場所に属するファイルを黙って渡すべきではありません。

**しないこと**：

- 自動レビューはこの確認に答えられます。作業ディレクトリ外のファイルを読む場合と同じです。
- ノートや会話でライブラリの画像をあなたに表示するときは確認しません。確認するのはエージェントが読むときだけです。

**調整するには**：上書き用のコピーを作って編集します。このルールを消すと、エージェントはどのライブラリのファイルも
確認なしで読めます。
