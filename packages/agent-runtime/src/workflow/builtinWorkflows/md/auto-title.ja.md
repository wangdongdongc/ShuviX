---
shuvix: workflow v1
shuvix-builtin: true
name: auto-title
shuvix-displayName: セッション名の自動生成
description: セッションに自動で名前を付ける —— 最初のプロンプトで手早く一つ、会話が溜まってから一度だけ練り直す。
shuvix-workflow-on:
  - trigger: session.prompt-accepted
    when: event.isDefaultTitle
  - trigger: session.turn-completed
    when: >-
      event.titleAutoGenerated && event.turnCount == 2
      && event.textMessageCount >= 3
---

## これは何をするか

二段構えのセッション自動タイトルを、一つのワークフローとして:

- **手早く** —— プロンプトが受理され、セッションがまだ既定のタイトルのままなら、その最初の
  メッセージを `titler` エージェントに渡し、粗いタイトルをその場で付けさせる。
- **練り直す** —— 二巡目が終わり、タイトルがまだ自動で付いたもの(利用者がセッションを
  改名していない)なら、溜まった会話から一度だけ作り直す。

`titler` エージェントは自分の `session` ツールでタイトルを適用し、何をしたかを下の `next`
結果契約で報告する。言い回しの規則を変えるなら `titler` エージェントを上書きし
(`~/.shuvix/agents/titler.md`)、タイトルを付ける**タイミング**を変えるならこのファイルを
上書きする(`~/.shuvix/workflows/auto-title.md`)。

```json schema=result
{
  "type": "object",
  "required": ["title"],
  "properties": {
    "title": { "type": "string", "description": "The title that was applied to the session" }
  }
}
```

```js workflow
const source =
  event.trigger === 'session.prompt-accepted' ? `User: ${event.promptText}` : event.recentText
const out = await run(
  'titler',
  [
    'Derive a concise title for this session from the conversation excerpt below,',
    'apply it with the session tool, then finish.',
    '',
    '<conversation>',
    source.slice(-1000),
    '</conversation>'
  ].join('\n'),
  { schema: schemas.result, description: 'session title' }
)
log(`title applied: ${out.title}`)
return out
```
